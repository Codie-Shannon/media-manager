# Manual tests

Manual verification records will cover:

- clean startup and shutdown;
- navigation and resize behavior;
- add, edit, remove, delete, and cancellation;
- folder hierarchy behavior;
- details and favourites;
- missing-file handling;
- playback or launch behavior using synthetic fixtures;
- metadata-provider and offline/manual-entry behavior.

No test may operate on a real personal media library.
